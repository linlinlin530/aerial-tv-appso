Aerial 1.96(APPSO)｜定制版说明与快速使用

基于 pengchujin/aerial-tv 的非官方定制分支。
原项目：https://github.com/pengchujin/aerial-tv
版本：1.96-appso（142）｜Android 5.0+｜standard 版

与本次定制所基于的原版相比，增加了什么？

① 中英文点阵字体
桌面中的中文、英文和数字改为圆点字形，采用 Nothing 风格的视觉灵感。
使用开源点阵字体，并非 Nothing 官方字体；网页内容仍使用网站自己的字体。

② 配置导出与导入
手机/电脑管理页新增“更多 → 配置备份”。
可导出 JSON，保存或恢复应用排序、文件夹、隐藏项、图标库选择、布局、
屏保选择及天气位置等配置。导入前会自动保存一份原配置，方便回滚。
不包含上传的图片/视频/自定义图标文件、已安装应用、系统权限或家长 PIN。

③ ifanr 文章屏保
在“个性化 → 屏幕保护程序 → 类型”中选择 ifanr。
自动获取最新文章的封面和标题，沿用照片轮播的淡入淡出与缓慢移动效果。
• 每篇约 15 秒，遥控器左右切换文章。
• 仅选中 ifanr 时启用每 2 小时的后台 RSS 更新任务。
• 切换其他屏保会取消任务；断网时继续使用已有缓存。
• 后台执行时间受电视系统和网络影响，不保证整点刷新。

④ 遥控器打开文章原文
第一次按确认键，提示“再次摁下确认键打开文章”；3 秒内再按确认才打开。
使用电视已有 WebView，采用桌面 UA 显示电脑版原网页，无需安装第三方浏览器。
不提取或重排正文；为旧 WebView 增加了证书信任和 CSS @layer 兼容处理。
文章页用上下键滚动、返回键退出。设置弹窗底部显示 Aerial 1.96(APPSO)。

快速安装 / 更新

1. 更新前，在“更多 → 配置备份”导出 JSON。
2. 开启电视 ADB 调试，电脑与电视连接同一网络。
3. 在 APK 所在目录运行，替换下面的“电视IP”：

   adb connect 电视IP:5555
   adb devices
   adb -s 电视IP:5555 install -r Aerial-1.96-APPSO.apk
   adb -s 电视IP:5555 shell am start -n app.orchard.tv/.MainActivity

设备状态应为 device，安装必须返回 Success。
同签名覆盖更新会保留原有配置，一般无需重新导入。不要先卸载或清除数据。
若提示签名冲突，请停止：本定制版不能直接覆盖官方签名或其他人签名的版本。

以上是 Android 5–8 的安装方式，维护者使用 Android 6 小米电视。首次接管桌面、授权、其他系统
安装优化及完整验收流程，请参考原项目说明：
https://aerial.qust.me/agent.md
注意：其中下载官方最新版的命令会获取官方包；安装本定制版应使用随附 APK。
不要停用电视原桌面。遇到需要 guard 版的固件，本 standard 包不适用。

需要保持 ADB 常开时，安装并授权后运行：
   adb -s 电视IP:5555 shell am broadcast -a app.orchard.tv.CONFIG -n app.orchard.tv/.guard.ConfigReceiver --ez keep_adb true

安装后检查
• 图标、排序和原配置仍在；设置弹窗显示 Aerial 1.96(APPSO)。
• 按主页键能回到 Aerial。
• ifanr 封面标题可见，约 15 秒切换；二次确认后打开对应原文。
• 检查原文排版、上下滚动和返回是否正常。
